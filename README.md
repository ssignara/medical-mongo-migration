# Projet n°5 du parcours Data Engineer

Ce projet automatise la migration de données médicales depuis un fichier CSV vers une base de données MongoDB, le tout conteneurisé avec Docker pour garantir la portabilité et la scalabilité.

## Contexte :

Un client du secteur médical fait face à des problèmes de scalabilité avec ses données patients. Cette solution propose une architecture Big Data moderne basée sur MongoDB, permettant une gestion efficace et évolutive de grandes quantités de données médicales.
Objectifs

✅ Migration automatisée de 55 000+ dossiers patients

✅ Conteneurisation complète avec Docker

✅ Sécurisation des accès avec authentification MongoDB

✅ Scalabilité horizontale

✅ Documentation complète pour maintenance et évolution
